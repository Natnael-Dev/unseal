# Unseal product plan

Decisions confirmed by Dexter on 23 November 2026.

- Name: Unseal.
- Goal: a convincing Dev3pack hackathon entry with a path to real users.
- Audience: Ethiopian university students and readers or creative communities. Choose one concrete resource to lead the first demonstration.
- Language: English for the first release.
- Initial material: a clearly identified builder-authored resource is acceptable; an external creator can join later.
- Promise: sponsor a finished, previewable resource for public sharing. Creator is responsible for quality and rights. Contributions have funding/default refund paths.
- Limitation: broadcasting unlocking material can expose it before a payment transaction succeeds. A content hash cannot establish quality or rights.
- Workflow: short-lived branches, small Conventional Commits, reviewable pull requests, and recorded checks for each change. Main should remain reproducible.

## Judging evidence

The published rubric covers Product and Technical signals. No official numerical weights verified. Show a clear user problem, meaningful public benefit, understandable demonstration, original Rust/Solana account rules, deployed devnet address, reproducible public source and live verification. Record real user feedback only when obtained. Declare pre-event work and dependencies. Browser scope addresses the overall track; native Android/store requirements need separate scope if pursued.
